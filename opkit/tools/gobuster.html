Gobuster

A fast brute-forcing tool for URIs (directories and files), DNS subdomains, virtual hosts, S3 and GCS buckets. Written in Go for high concurrency. Operates in distinct modes: dir, dns, vhost, s3, gcs, fuzz, and tftp.

dir dns vhost s3 / gcs High Concurrency --exclude-length WAF Bypass Cloud Enumeration
First 3 Commands — Quick Start
Three modes that cover 90% of web enumeration.
$ gobuster dir -u https://target -w /usr/share/seclists/Discovery/Web-Content/raft-medium-directories.txt -x php,bak,old --exclude-length <false-positive-length> Calibrated directory scan
$ gobuster vhost -u https://target -w /usr/share/seclists/Discovery/DNS/subdomains-top1million-5000.txt --append-domain VHost discovery
$ gobuster dns -d target.com -w /usr/share/seclists/Discovery/DNS/subdomains-top1million-5000.txt DNS subdomain brute-force

Common Pitfalls & Operational Reality

Why is Gobuster returning 200 for everything? — The Wildcard Trap.
  • Wildcard DNS / Catch-all responses: Many modern applications return a 200 OK with a custom "Not Found" page for every request. Gobuster will report every single word in your wordlist as a hit, making the output useless.
  • The --exclude-length fix: To filter these out, first make a request to a guaranteed-random path (e.g. curl -s -w '%{size_download}' https://target/randomxyz), note the response size, and pass it to --exclude-length. Example: --exclude-length 0 (for truly empty responses) or --exclude-length 2899 (a common catch-all page size).
  • vhost --append-domain is not optional: Without --append-domain, Gobuster tests the plain word as the Host header (e.g., Host: admin), not admin.target.com. It will miss every virtual host unless the base domain is appended.
  • -r (follow redirects) creates false hits: Enabling -r makes Gobuster follow 301/302 redirects, which can lead to it reporting a redirect chain as a valid directory. Leave it disabled for cleaner directory discovery.
Wordlists and User-Agents matter more than threads.
  • Wordlist choice: dirb/common.txt is legacy. Use SecLists raft-medium-directories.txt (directories), raft-medium-files.txt (files), and subdomains-top1million-5000.txt (DNS/VHost).
  • Default User-Agent is blocked: Gobuster's default UA is gobuster/X.X. Many WAFs and CDNs block this immediately. Always spoof a browser UA: -a "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36".
  • Threads are aggressive: Default -t 10 is generally fine. Increasing to -t 50 or -t 100 can trigger rate limits or lock accounts. Use --delay 1500ms for fragile targets.

dir Mode — Directory & File Brute-Force

Calibrated directory scan with --exclude-length
Filter out custom 404/catch-all response sizes to eliminate thousands of false-positive hits. Measure with: curl -s -w '%{size_download}' https://target/randomxyz.
$ gobuster dir -u https://target -w /usr/share/seclists/Discovery/Web-Content/raft-medium-directories.txt --exclude-length <measured-size>
Extension-aware backup and source code hunting
The highest-yield technique for finding forgotten source code, database dumps, vim swap files, and config leaks.
$ gobuster dir -u https://target -w /usr/share/seclists/Discovery/Web-Content/raft-medium-directories.txt -x php,bak,old,backup,swp,zip,sql
Status code filtering and blacklisting
Gobuster displays positive status codes (200, 204, 301, 302, 307, 401, 403) by default. Use -b to blacklist noise.
$ gobuster dir -u https://target -w /usr/share/seclists/Discovery/Web-Content/raft-medium-directories.txt -s "200,204,301,302,307" -b "403,404"
Authenticated directory scanning (Cookies & Basic Auth)
Send session cookies with -c and HTTP Basic Auth credentials with -U and -P for authenticated enumeration.
$ gobuster dir -u https://target -w /usr/share/seclists/Discovery/Web-Content/raft-medium-directories.txt -c "session=abc123xyz"
$ gobuster dir -u https://target -w /usr/share/seclists/Discovery/Web-Content/raft-medium-directories.txt -U admin -P password123

dns Mode — Subdomain Enumeration

Standard subdomain brute-force
Brute-force DNS subdomains using wordlists against target domain.
$ gobuster dns -d target.com -w /usr/share/seclists/Discovery/DNS/subdomains-top1million-5000.txt
Resolve and display IP addresses
Show discovered subdomains alongside their resolved IP addresses using -i.
$ gobuster dns -d target.com -w /usr/share/seclists/Discovery/DNS/subdomains-top1million-5000.txt -i resolve IPs
Wildcard DNS detection and continuation
Gobuster warns and aborts if wildcard DNS is detected. Use --wildcard to force continuation.
$ gobuster dns -d target.com -w /usr/share/seclists/Discovery/DNS/subdomains-top1million-5000.txt --wildcard
Custom high-speed DNS resolver
Point DNS queries to a fast public resolver (e.g. 1.1.1.1 or 8.8.8.8) to bypass local rate limits and poisoned caches.
$ gobuster dns -d target.com -w /usr/share/seclists/Discovery/DNS/subdomains-top1million-5000.txt -r 1.1.1.1

vhost Mode — Virtual Host Discovery

--append-domain is mandatory: Without it, Gobuster tests Host: word instead of Host: word.target.com. Always pass --append-domain so virtual hosts match the fully qualified domain name.
Standard virtual host discovery
Find vhosts served on the same web server IP by mutating the HTTP Host header.
$ gobuster vhost -u https://target -w /usr/share/seclists/Discovery/DNS/subdomains-top1million-5000.txt --append-domain
Filter catch-all vhosts with --exclude-length
Drop default zero-byte or static catch-all vhost responses returned by web servers.
$ gobuster vhost -u https://target -w /usr/share/seclists/Discovery/DNS/subdomains-top1million-5000.txt --append-domain --exclude-length 0
Scan vhosts directly targeting an IP address
Probe a specific host IP while enforcing the base domain name for Host header assembly.
$ gobuster vhost -u http://10.10.10.1 -w /usr/share/seclists/Discovery/DNS/subdomains-top1million-5000.txt --domain target.com --append-domain
Compatibility note: --domain in vhost mode requires Gobuster 3.6+. On older versions (3.0–3.5), add target.com to /etc/hosts pointing to the IP, then use -u http://target.com instead.

fuzz Mode — URL & Parameter Fuzzing

Gobuster's fuzz mode replaces the FUZZ keyword anywhere in the URL, custom request headers, or body data — enabling lightweight parameter discovery.
GET parameter and endpoint fuzzing
Substitute the FUZZ keyword to discover hidden query parameters or unlinked endpoints.
$ gobuster fuzz -u "https://target/page?FUZZ=test" -w /usr/share/seclists/Discovery/Web-Content/burp-parameter-names.txt --exclude-length <measured-size>
POST body parameter fuzzing
Fuzz authentication form fields or API parameters inside HTTP POST bodies using -X POST and -d.
$ gobuster fuzz -u https://target/login -X POST -d "user=FUZZ&pass=test" -w /usr/share/seclists/Usernames/top-usernames-shortlist.txt -H "Content-Type: application/x-www-form-urlencoded"

s3 & gcs Modes — Cloud Bucket Enumeration

Enumerate publicly accessible, misconfigured, or listing-enabled cloud storage buckets on AWS and Google Cloud Platform without cloud credentials.
Amazon S3 bucket enumeration
Brute-force public Amazon S3 bucket names using wordlists to identify readable or writable buckets.
$ gobuster s3 -w bucket-names.txt
Google Cloud Storage (GCS) enumeration
Brute-force public Google Cloud Storage bucket names to spot exposed assets.
$ gobuster gcs -w bucket-names.txt

tftp Mode — TFTP File Enumeration

Enumerate files on a TFTP server
Brute-force filenames on UDP port 69 against a TFTP server (common in network appliance and PXE boot environments).
$ gobuster tftp -s tftp.target.com -w /usr/share/seclists/Discovery/Web-Content/raft-medium-files.txt

Quick Cheatsheet

Calibrated dir
gobuster dir -u https://target -w /usr/share/seclists/Discovery/Web-Content/raft-medium-directories.txt -x php,bak,old
With extensions
gobuster dir -u https://target -w list.txt -x php,bak,old
DNS subdomain
gobuster dns -d target.com -w subdomains.txt
VHost discovery
gobuster vhost -u https://target -w subs.txt --append-domain
Filter length
gobuster dir -u https://target -w list.txt --exclude-length 2899
WAF bypass UA
gobuster dir -u https://target -w list.txt -a "Mozilla/5.0"
Replay through BurpCHAIN
gobuster dir -u https://target -w list.txt --proxy http://127.0.0.1:8080
ffuf for recursionCHAIN
ffuf -w list.txt -u https://target/FUZZ -recursion -recursion-depth 2 -ac
Feed to SQLmapCHAIN
sqlmap -u "https://target/page?param=1" --batch --dbs
