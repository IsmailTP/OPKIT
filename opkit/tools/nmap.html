Nmap

The industry-standard network exploration tool and security scanner. Used for host discovery, port scanning, service version detection, OS fingerprinting, and running NSE automation scripts.

Port Scanning Target Scope Host Discovery Service Detection OS Fingerprinting NSE Scripting Firewall Evasion
First 3 Commands — Quick Start
Standard field triage progression — start here before deep or targeted scanning
$ nmap -sV -sC -T4 <target> quick triage
$ nmap -p- -sV --min-rate 2000 -T4 <target> full port with rate control
$ nmap -Pn -sV <target> skip ICMP when host seems down

Target Scope Control

Scope Discipline & Engagement Boundaries
In real security engagements, staying inside authorized scope is the single most important discipline. Striking an out-of-scope gateway, production database, or third-party appliance is a critical ROE breach. Always sanity-check parsed ranges with -sL before transmitting active probes.
Dry-run / list only (scope sanity check)
Prints target list without sending a single packet; verifies scope and DNS resolution before firing
$ nmap -sL 10.10.10.0/24
Exclude specific hosts from CIDR sweep
Omit gateways, printers, domain controllers, or out-of-scope production machines
$ nmap 10.10.10.0/24 --exclude 10.10.10.1,10.10.10.254
Exclude targets from file (blocklist)
Load forbidden CIDRs or out-of-scope IP ranges from engagement ROE files
$ nmap 10.10.10.0/24 --excludefile scope_blocklist.txt
Read targets from input list
Batch scan approved IP lists, CIDRs, or hostnames with full output logging
$ nmap -iL targets.txt -sV -oA from_file_scan

Host Discovery

Ping sweep (no port scan)
Discover live hosts without scanning ports
$ nmap -sn 192.168.1.0/24
$ nmap -sn 192.168.1.1-254
ARP ping (local network)
Fast discovery on same subnet; bypasses firewall rules
# nmap -PR -sn 192.168.1.0/24
Disable all host discovery (treat all as up)
Useful when ICMP is blocked
$ nmap -Pn 10.10.10.1

Scan Types

SYN scan — fast / half-open
Default when run as root; fast TCP scan that sends SYN and tears down with RST. Note: "Stealth" is a legacy myth — modern IDS/IPS and EDR flag incomplete handshakes immediately.
# nmap -sS 10.10.10.1
TCP connect scan
Full 3-way connection; works without root privileges; highly visible in application logs
$ nmap -sT 10.10.10.1
UDP scan (rate-limited timeout alert)
A full 65,535-port UDP scan can take 36+ hours because Nmap waits for timeouts on unresponsive ports. Always start with -sU --top-ports 100 or a targeted list (53, 161, 123, 500).
# nmap -sU --top-ports 100 10.10.10.1
# nmap -sU -p 53,67,68,123,161,500 10.10.10.1
# nmap -sU 10.10.10.1
ACK scan — firewall ruleset mapping
Doesn't tell you open/closed; it maps stateful vs stateless firewall filters (RST response = unfiltered, drop/ICMP unreachable = filtered)
# nmap -sA 10.10.10.1
Window scan — TCP window size port detection
ACK variant; observes the TCP window size in returning RST packets to leak open vs closed on certain OS stacks
# nmap -sW 10.10.10.1
Maimon scan (FIN/ACK combo)
Sends FIN/ACK probes named after Uriel Maimon; effective against BSD-derived stacks that drop the probe on open ports
# nmap -sM 10.10.10.1
NULL, FIN & Xmas scans — stateless filter bypass
Bypasses stateless filters that only watch SYN. RFC 793 standard behavior: closed ports return RST; open ports drop packet silently.
Windows Incompatibility Warning: NULL (-sN), FIN (-sF), and Xmas (-sX) scans are unreliable against Windows hosts and Cisco devices. The Windows TCP/IP stack responds with RST to all non-SYN probes regardless of port state, making every port appear closed.
# nmap -sN 10.10.10.1
# nmap -sF 10.10.10.1
# nmap -sX 10.10.10.1
Aggressive scan (all at once)
Enables OS detection, version detection, script scanning, and traceroute
# nmap -A -T4 10.10.10.1
Full port scan + service version + default scripts
Most thorough single-command recon sweep
# nmap -sV -sC -p- 10.10.10.1

Low-Level Performance Tuning

-T4 is merely an aggregate template. Production-grade full-port scans and internal sweeps require explicit flag overrides to prevent scans from stalling across high-latency hops or rate-limited hosts.

Flag OverridePurpose & MechanicsSyntax Example
--min-rate 1000 Guarantees packets are sent at least at this rate; ensures full 65,535-port scans finish in minutes rather than hours --min-rate 1000
--max-retries 2 Reduces probe retransmissions when packet loss is low; drastically speeds up scans by cutting wait cycles --max-retries 2
--host-timeout 5m Prevents Nmap from hanging indefinitely on one unresponsive or tarpitted target --host-timeout 5m
--min-hostgroup 64 Processes more hosts in parallel on CIDR sweeps instead of small default batches --min-hostgroup 64
Full port scan with rate, retry & timeout overrides
The gold-standard high-throughput scanning recipe for internal engagements
# nmap -p- -sV --min-rate 2000 --max-retries 2 --host-timeout 5m -T4 10.10.10.1

NSE Scripts

Scripts live in /usr/share/nmap/scripts/. Browse categories with ls /usr/share/nmap/scripts/ | grep <keyword>.
Default safe scripts
Run safe, non-intrusive discovery and banner enumeration scripts
$nmap -sC 10.10.10.1
Vulnerability scan (--script vuln)
Run all vuln-category scripts against target
Critical Production Risk Warning: The vuln category includes scripts that actually trigger known software vulnerabilities, while the dos and exploit categories can crash unpatched targets or crash services. Nmap's documentation warns against running these against unverified production systems without formal risk assessment and ROE authorization.
#nmap --script vuln 10.10.10.1
Precise SMB vulnerability check (EternalBlue)
Much faster and quieter than running all wildcard smb-vuln-* scripts
#nmap -p 445 --script smb-vuln-ms17-010 10.10.10.1
SMB message signing status (relay attack check)
Tells you if SMB signing is disabled or not required — determining if NTLM relay attacks are viable
#nmap -p 445 --script smb-security-mode,smb2-security-mode 10.10.10.1
FTP anonymous login + vsftpd backdoor check
Tests the two most prevalent FTP security flaws in a single shot
$nmap -p 21 --script ftp-anon,ftp-vsftpd-backdoor 10.10.10.1
DNS zone transfer attempt (AXFR)
Single command attempt to dump the entire authoritative DNS zone table from target name server
$nmap -p 53 --script dns-zone-transfer 10.10.10.1
SSH authentication methods enumeration
Inspect accepted auth methods (password vs publickey) prior to launching brute-force attacks
$nmap -p 22 --script ssh-auth-methods 10.10.10.1
Wildcard script category execution
Run all scripts matching a wildcard pattern against specific open ports
$nmap --script "http-*" -p 80,443 10.10.10.1
#nmap --script "smb-vuln-*" -p 445 10.10.10.1
SMB enumeration
Enumerate shares, users, OS via SMB
#nmap --script smb-enum-shares,smb-enum-users -p 445 10.10.10.1
HTTP enumeration
Headers, methods, title, robots.txt
$nmap --script http-enum,http-headers,http-methods -p 80,443 10.10.10.1

Firewall / IDS Evasion

Authorized Evasion Testing Only
Decoys, fragmentation, and source-port spoofing send packets with forged or manipulated source addresses to third parties and network devices. Only use when Rules of Engagement explicitly permit evasion testing. Never run -D RND against third-party infrastructure without prior written authorization.
TechniqueCommandNotes
Fragmentation nmap -f <target> Splits TCP header across packets; bypasses stateless filters that only inspect the first packet
Decoys nmap -D RND:10 <target> Mixes traffic from 10 random decoy IPs to conceal the real scanner address
Decoys + real IP marker nmap -sS -D 10.0.0.1,10.0.0.2,ME <target> Controls where the real IP (ME) appears in the decoy sequence
Source port spoofing nmap --source-port 53 <target> Uses a port firewalls usually allow (DNS); bypasses poorly configured ACLs
Packet padding nmap --data-length 24 <target> Defeats size-based fingerprinting and signature detection
Slow evasion nmap -T1 --scan-delay 1s <target> Stretches probe intervals to stay under rate thresholds and IDS alert ceilings
IP fragmentation (8-byte MTU split)
Splits TCP header across multiple packets to bypass legacy inspection engines
# nmap -f 10.10.10.1
# nmap --mtu 16 10.10.10.1
Decoy scanning (traffic mixing)
Send probes with random decoy addresses so target logs show scans from multiple IPs
# nmap -D RND:10 10.10.10.1
# nmap -sS -D 10.0.0.1,10.0.0.2,ME 10.10.10.1
Source port spoofing & payload padding
Originates probes from trusted ports (53 DNS, 88 Kerberos) and appends random bytes
# nmap --source-port 53 10.10.10.1
# nmap --data-length 24 10.10.10.1
# nmap -T1 --scan-delay 1s 10.10.10.1
